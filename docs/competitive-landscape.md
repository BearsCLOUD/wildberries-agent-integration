# Конкурентный контур и источники

Плагин закрывает агентский сценарий «данные → объяснение → действие», а не пытается копировать
полноценный кабинет аналитического сервиса. В сравнении с классическими сервисами Wildberries
(`MPSTATS`, `Moneyplace`, `MarketGuru`, `SellerFox`, `MPSpace`) основной фокус — русскоязычные
инструменты MCP, бесплатный доступ для агента, прозрачные расчёты и сохранение ownership Seller.

| Контур | Что ожидает продавец от рынка | Граница плагина |
| --- | --- | --- |
| Конкуренты и цены | Карточки, цены, позиции и динамика по категории | `wb_wildberries_proxy` получает только разрешённые снимки/операции; `wb_competitor_analysis` и `wb_competitive_price` считают только явно переданные сопоставимые строки |
| SEO и карточки | Семантика, структура карточки и рекомендации | `wb_seo_analytics` даёт эвристику; навыки `product-card`, `design-system` и `product-photo-generation` готовят черновик, но не публикуют карточку |
| Продажи по регионам | Спрос, склады, логистика и региональные срезы | `wb_sales_by_region` использует только фактическое поле региона; склад не переименовывается в регион покупателя |
| Погода и спрос | Гипотезы сезонности и локального спроса | `wb_sales_weather_impact` показывает наблюдаемую корреляцию с оговоркой о причинности и качестве данных |

## Источники и лицензии

- Официальный [Wildberries API](https://dev.wildberries.ru/ru/openapi/api-information) — источник
  собственных данных продавца. Публичного документированного API продаж конкурентов в контракте
  плагина нет.
- Для внешних конкурентных данных допускается только лицензированный провайдер с отдельным
  серверным адаптером и договором. В качестве проверяемого кандидата существует
  [MPSTATS REST API](https://mpstats.io/integrations/docs/description/); его токен, тариф и право
  перераспределять данные не входят в репозиторий.
- `Moneyplace`, `MarketGuru`, `SellerFox` и `MPSpace` рассматриваются как UI/партнёрские источники
  до получения от поставщика документированного API и условий. Скрапинг кабинетов, cookies,
  undocumented storefront endpoints и обход ограничений запрещены.
- Для погодных рядов production должен использовать коммерчески разрешённый API. Бесплатный
  endpoint Open-Meteo не следует считать коммерческим источником: см. [условия](https://open-meteo.com/en/terms),
  [тарифы Customer API](https://open-meteo.com/en/pricing) и [лицензию](https://open-meteo.com/en/license).
  Российский кандидат после согласования условий — [Gismeteo API v4](https://docs.gismeteo.net/v4/weather).

До подключения провайдера его данные не подменяются синтетикой: инструмент возвращает
`source_required` или `gateway_not_configured`, а отчёт сохраняет источник, период, регион и
ограничения наблюдения.
