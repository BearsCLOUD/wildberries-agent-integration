# Интеграция агента Wildberries

Канонический каталог плагина Codex/Claude: шестнадцать русскоязычных навыков
и подключение к публичному MCP `https://wb.seller.bears.ru/mcp`.
Codex использует `.mcp.json`, Claude — `claude/mcp.json`; локальный Python-сервер
для установки не требуется. Локальный stdio-запуск предназначен для разработки.

См. [корневое описание](../../README.md), [SPEC](../../SPEC.md),
[правила безопасности](SECURITY.md), [приватность](PRIVACY.md), [условия](TERMS.md) и
[поддержку](SUPPORT.md).
