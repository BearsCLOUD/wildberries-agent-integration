# Анализ отзывов Wildberries

1. Уточни поставщика, товар, глубину выборки и нужен ли только список без ответа.
2. Получи отзывы через `wb_wildberries_proxy` с operation `feedbacks`; передавай только bounded
   `nm_id`, `is_answered`, `take`, `skip` и `order`.
3. Для сравнения средней оценки нескольких товаров используй operation `feedback_average` с
   `nm_ids`. Не проси и не принимай токен Wildberries: Seller выбирает credential владельца.
4. Сгруппируй наблюдения по товару, оценке и повторяющейся теме. Отдельно покажи низкие оценки,
   отзывы без ответа и темы, которые требуют изменения товара или карточки.
5. Укажи размер и ограничения выборки. Не превращай отсутствие отзывов в положительный вывод и
   не публикуй ответы от имени продавца.
