# Загрузка себестоимости

Используй `wb_upload_cost_price`, когда пользователь явно указал поставщика, `nm_id` и сумму.
Инструмент сначала показывает параметры изменения и записывает себестоимость одного товара через Seller только при явном `confirm=true`. Результат не содержит токенов.

## Порядок

1. Проверь поставщика, `nm_id` и сумму себестоимости в рублях за единицу.
2. Первый вызов сделай без подтверждения и покажи пользователю точные параметры перезаписи.
3. Только после явного согласия повтори вызов с `confirm=true`.
4. Покажи результат и не называй запись успешной при ошибке сервиса.

## Безопасность

- Никогда не проси и не показывай токен Wildberries, cookie или bearer.
- Не записывай себестоимость в другого поставщика или другой `nm_id` по догадке.
- Не записывай другого поставщика или другой `nm_id` по догадке; при отсутствии данных задай уточняющий вопрос.
- Для вопроса «какая себестоимость нужна для маржи» используй `unit-economics`, а не запись в Seller.

## Пример

**Запрос:** «Установи себестоимость 320 ₽ для nm_id 123456789 у поставщика 31460».

**Ответ:** Покажи параметры перезаписи, получи явное подтверждение, затем вызови инструмент с `confirm=true` и сообщи фактический статус Seller.
