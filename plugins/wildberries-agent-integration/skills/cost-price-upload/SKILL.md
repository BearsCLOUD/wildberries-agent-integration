# Загрузка себестоимости

Используй `wb_upload_cost_price` только после явного подтверждения пользователя. Инструмент
записывает себестоимость одного `nm_id` для выбранного поставщика через Seller и возвращает
статус операции без токенов.

## Порядок

1. Подтверди поставщика, `nm_id` и сумму себестоимости в рублях за единицу.
2. Сообщи, что действие изменит данные Seller.
3. Вызови инструмент с `confirm=true` только после ответа пользователя «подтверждаю» или эквивалентного согласия.
4. Покажи результат и не называй запись успешной при ошибке сервиса.

Без `confirm=true` инструмент безопасно остановится и ничего не отправит в Seller.

## Безопасность

- Никогда не проси и не показывай токен Wildberries, cookie или bearer.
- Не записывай себестоимость в другого поставщика или другой `nm_id` по догадке.
- Не выполняй массовые или повторные записи без отдельного подтверждения каждой операции.
- Для вопроса «какая себестоимость нужна для маржи» используй `unit-economics`, а не запись в Seller.

## Пример

**Запрос:** «Установи себестоимость 320 ₽ для nm_id 123456789 у поставщика 31460».

**Ответ:** Повтори поставщика, товар и сумму, запроси подтверждение, затем вызови инструмент с
`confirm=true` и сообщи фактический статус Seller.
