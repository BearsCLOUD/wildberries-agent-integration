# Загрузка себестоимости

Используй `wb_upload_cost_price`, когда пользователь явно указал поставщика, `nm_id` и сумму.
Инструмент сначала запрашивает у Gateway preview и записывает себестоимость одного товара через
Seller только после явного `confirm=true` с тем же `confirmation_token`. Результат не содержит
токенов Wildberries.

## Порядок

1. Проверь поставщика, `nm_id` и сумму себестоимости в рублях за единицу.
2. Первый вызов сделай с `confirm=false` без `confirmation_token`; сохрани возвращённый token для
   следующего вызова и покажи пользователю точные параметры перезаписи и срок его действия
   (`expires_in=300`), но не проси пользователя вводить или пересказывать token.
3. Дождись отдельного сообщения пользователя с подтверждением именно этих поставщика, товара и
   суммы, затем повтори вызов с `confirm=true`, теми же параметрами и полученным
   `confirmation_token`.
4. При изменении поставщика, `nm_id` или суммы начни новый preview и не используй прежний token.
5. Покажи результат и не называй запись успешной при ошибке сервиса. Для `write_status_unknown` не
   повторяй запись автоматически.

## Безопасность

- Никогда не проси и не показывай токен Wildberries, cookie или bearer.
- Не записывай себестоимость в другого поставщика или другой `nm_id` по догадке.
- При отсутствии поставщика, `nm_id` или суммы задай уточняющий вопрос.
- Для вопроса «какая себестоимость нужна для маржи» используй `unit-economics`, а не запись в Seller.

## Пример

**Запрос:** «Установи себестоимость 320 ₽ для nm_id 123456789 у поставщика 31460».

**Ответ:** Покажи параметры перезаписи и срок действия token, получи отдельное явное подтверждение,
затем вызови инструмент с `confirm=true` и тем же `confirmation_token`; сообщи фактический статус
Seller.
